# 印刷套准复核台

接口把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后写回。页面每隔一秒看一次，直到结论出现。

已出结论的印张可由印刷员在「导出冻结」页勾选签发生成只读冻结包，冻结签发当时的偏差、结论与理由。签发后再改现场偏差只刷新总表当前行，包内数字不受牵连。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、改偏差重判、签发冻结包 |
| checker | check123456 | 只看，可翻包查看冻结包，不能签发 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. printer 打开「导出冻结」页，勾选封面-01、内页-09 后点「签发冻结包」，生成一个只读包；两笔从可签发列表移到已签发包。
5. 回总表分别对这两笔改现场偏差（封面青改为 0.5、内页青改为 0.08）保存并重判：总表当前行结论翻转为套不准/套准，行仍带「已冻结」标记。
6. 再从「导出冻结」页翻包打开，包内仍是签发当时的 0.05/套准与 0.40/套不准，与总表当前数字不同。
7. checker 登录后可打开「导出冻结」页翻包看明细，但勾选框禁用、没有签发按钮（直接调接口返回 403）。
