# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

已出结论的印张可由印刷员**签发导出冻结包**：签发瞬间把当时的印张偏差、结论与理由复制成只读快照。签发之后再改现场偏差、重新判定，只刷新总表当前行；冻结包内数字保持签发当时，不受牵连。质检可翻包查看，不能签发。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可签发冻结包 |
| checker | check123456 | 只看（可翻包，不能签发） |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. 菜单「导出冻结包」：可签发列表列出全部已出结论且未冻结的印张；勾选两笔签发，生成一个只读冻结包，包内明细为签发当时的偏差、结论、理由。
5. 回到总表对这两笔点「改现场偏差重判」（如封面-01 青改 0.50），总表当前行刷新为新数字、新结论；再打开冻结包，包内仍是签发当时的数字。
6. 已签发印张不重复出现在可签发列表；重复签发返回 409。
7. checker 登录「导出冻结包」页可看包列表与包内明细，但没有勾选框与签发按钮，直接调接口签发返回 403。
